### Prerequisites

##### A server running Easypanel [https://easypanel.io/](https://easypanel.io/)

[Easypanel](https://easypanel.io) is a self-hosted deployment platform that manages Docker containers for you through a web UI. It provides a pre-built [Fider template](https://easypanel.io/templates/fider) that deploys Fider together with its Postgres database in one click.

### Installing and Running

This guide assumes you already have Easypanel installed on your server.

##### Step 1: Deploy the Fider template.

From the Easypanel dashboard, create a new project and select the Fider template. Easypanel will provision the Fider app and a Postgres database, and wire the `DATABASE_URL` between them automatically.

##### Step 2: Configure your domain.

Set the domain you want to use for your Fider instance under the app's Domains tab. Easypanel handles TLS certificates automatically.

##### Step 3: Configure your email provider.

Fider isn't going to work very well without a way to send emails. Fider's various email options are [listed here](/hosting-instance#installing-and-running). Set the relevant `EMAIL_*` environment variables under the app's Environment tab in Easypanel, then redeploy.

That's pretty much all there is to it!
